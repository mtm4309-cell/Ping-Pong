## PING PONG [April 2024 - May 2024] ##

 ## Introduction ##
This is a **Retro-Style 2D Ping Pong Game built from scratch using the Pygame Module in Python.** 
It features an **automated opponent**, **various sound effects**, a **custom UI menu**, and **retro pixel typography**.


## Features ##

--> **Dynamic Automated Opponent:** An Automated Opponent Paddle that tracks the position of the ball on the fly.  

--> **Custom UI Menu:** An Interactive Main Menu and Pause Menu built with custom button handling.  

--> **Audio and Sound Effects:** Dedicated to various events that occur in the game, such as when the ball is hit, passes through the paddle, and winning and losing sound effects.  

--> **First-to-5:** The game is played until either the opponent or the player gets 5 points, at which point the game ends.  

--> **Retro Aesthetics:** The game features pixel backgrounds and arcade-style topography     
*[Note: Many of the backgrounds and fonts were downloaded online]*  


## How to Download & Play

### Prerequisites
Make sure you have **Python 3.x** installed on your system. You can download it from [python.org](https://www.python.org/).

### Step-by-Step Instructions

1. **Download the Game:**
   - Click the green **Code** button at the top right of this repository page.
   - Select **Download ZIP**.
   - Extract the downloaded `.zip` file to a folder on your computer.

2. **Install Required Packages:**
   - Open your Terminal / Command Prompt inside the extracted folder.
   - Run the following command to install PyGame:
     ```bash
     pip install pygame
     ```

3. **Launch the Game:**
   - In the same terminal window, run:
     ```bash
     python main.py
     ```
     *(If your main script uses a different name, replace `main.py` with your file name, e.g., `ping_pong.py`)*
